# Online Matrimonial Project in PHP

An online matrimonial web portal that enables users to register, search, and find life partners based on their preferences. This project is a dynamic, fully responsive web application powered by PHP and MySQL, complete with an administrative backend.

## 🚀 Features

- **User Registration & Profile Creation:** Users can register and create detailed profiles including personal information, preferences, and photos.
- **Advanced Search:** Find profiles by age, marital status, religion, community, education, etc.
- **Partner Preferences:** Define partner requirements to match and find compatible profiles.
- **Dynamic Admin Dashboard:** Admin can manage registered users, preferences, and overall portal settings.
- **Responsive Design:** Fully styled using Bootstrap and custom CSS.

## 🛠️ Tech Stack

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript, jQuery, Bootstrap
- **Slider/Animations:** FlexSlider, Magnific Popup

## 💻 Installation & Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/vijaymahes9080/online-matrimonial-project-php.git
   ```

2. **Database Configuration:**
   - Import the database schema from [db/matrimony.sql](file:///d:/BACKUP/projects/PHP%20project/online-matrimonial-project-in-php/db/matrimony.sql) into your MySQL/phpMyAdmin server.
   - Update connection settings in [includes/dbconn.php](file:///d:/BACKUP/projects/PHP%20project/online-matrimonial-project-in-php/includes/dbconn.php) and [functions.php](file:///d:/BACKUP/projects/PHP%20project/online-matrimonial-project-in-php/functions.php) if your username/password differs from the default `root` / empty password.

3. **Deploy on Local Server:**
   - Move the project directory to your web server root directory (e.g., `htdocs` for XAMPP or `www` for WAMP).
   - Start Apache and MySQL from your control panel.
   - Open your browser and navigate to `http://localhost/online-matrimonial-project-in-php/`.
